# Curadoria de Dados

A curadoria de dados é um dos principais aspectos do Gerenciamento de Dados de Pesquisa (GDP), do inglês Research Data Management (RDM).
Ela envolve a captura, avaliação, descarte, descrição, preservação, acesso, reutilização e transformação de dados de pesquisa.
A curadoria de dados assegura o uso adequado dos dados desde sua criação até a garantia de sua aplicação para o fim a que se destinam.
Data curation also enables you to easily access datasets and information that you need in an organised format, once shared in a Data Repository [{term}`def<Data repository>`].
Você pode imaginar que, se não seguir o processo de curadoria de dados, será difícil acessar esses dados.

## Pipeline de Curadoria de Dados

### 1. Captura de Dados

A captura de dados é o processo de reunir ou coletar dados de diferentes fontes, que serão então processados e usados para determinados fins.
Essas fontes podem ser artigos científicos em formato eletrônico ou bancos de dados, como bancos de dados eletrônicos, entre outras.
Esta etapa foca em garantir que os dados capturados sejam realmente adequados ao propósito e estejam prontos para curadoria.

- See {ref}`Finding data<rr-rdm-find>` for more information

### 2. Avaliação de dados

In data appraisal, you are required to select the appropriate data by entering, digitizing, transcribing, checking, validating and cleaning the data.
You may also need to anonymise or pseudoanonymise the data where necessary.
A sua política de avaliação e seleção deve garantir consistência, transparência e tomada de decisão responsável.

- See [Crystal Lewis's blog on cleaning data](https://cghlewis.com/blog/data_clean_02) for more detailed information.
- Watch [DataONE Webinar: Tidying Your Data](https://vimeo.com/378621271)

### 3. Descarte de Dados

O descarte de dados envolve a eliminação de dados que não foram selecionados para preservação.
É necessário ter uma política de avaliação que te oriente sobre os dados necessários para arquivamento, redistribuição, transferência de custódia ou propriedade, ou destruição dos dados de pesquisa.

### 4. Descrição de Dados

A descrição de dados exige as capacidades de interpretação de dados, produção de resultados de pesquisa, criação de publicações, anonimização de dados, visualização de dados, validação de dados, e preparação de dados para preservação.
So it is important that you describe the research data so that it is discoverable and usable over time, {ref}`Documentation and Metadata<rr-rdm-metadata>` for more information.
Também existem padrões de metadados que já existem para auxiliar na padronização das descrições.

### 5. Preservação de Dados

See {ref}`Data Repositories<rr-rdm-repository>` and {ref}`Sharing and Archiving Data<rr-rdm-sharing>` for more information.

### 6. Acesso a Dados

Data access entails distributing data, sharing data, publishing data, linking data to outputs, controlling access, establishing copyright and promoting or disseminating the data to wider audiences to access it or reuse it.
You can make the data freely available online to anyone who may be interested in reading it or you may restrict access of the data or provide an option of how to access the data.
See {ref}`Data Repositories<rr-rdm-repository>` and {ref}`Sharing and Archiving Data<rr-rdm-sharing>` for more information.

### 7. Transformação de Dados

A transformação de dados é a prática de examinar grandes conjuntos de dados para gerar novas informações.
Você pode reanalisar os dados de pesquisa e estabelecer relações que talvez não tenham sido descobertas anteriormente.
