# Guia para colaboração

_**This guide covers topics related to effective and inclusive collaboration.**_

A ciência dos dados é definida pela sua interdisciplinaridade.
O nosso trabalho só pode atingir o seu maior potencial se houver diversas equipes de pessoas envolvidas na concepção e na entrega da pesquisa ou produto.

Há muitas competências diferentes que são necessárias para trabalhar bem em grupos com uma vasta gama de conhecimentos.
In this guide, we welcome contributions in developing guidance on the following (but not limited to) topics:

- Projetando um projeto que agradece as contribuições
- Distributed collaboration with git
- Revisando as contribuições dos membros da equipe
- Trabalho remoto
- Executando um evento inclusivo
- Coordenando uma reunião
- Definindo expectativas explícitas
- Cocriação participativa

Check out our [contributing guidelines](#ch-contributing) to get involved.
